# Dynamic Responses Overview

MockHub provides several features to move beyond static files and create dynamic, stateful, and realistic mock APIs.

This section covers the tools available for creating dynamic responses.

1.  **[Sequences](sequences.md)**: Serve a series of different responses to repeated requests to the same endpoint.

2.  **[Sidecar Metadata](metadata.md)**: Control status codes, headers, and simulated latency for any response file.

3.  **[Jinja2 Templating](templating.md)**: Inject request data, state, or random values into your response payloads.

4.  **[Python Hooks](hooks.md)**: Implement custom logic in Python for ultimate control over the response.
